# 💬 Кроссплатформенный мессенджер (Flutter + PocketBase + WebRTC)

Современное клиент-серверное приложение для обмена текстовыми сообщениями и совершения аудио/видеозвонков в реальном времени. Проект разработан с использованием архитектурного подхода, обеспечивающего высокую производительность, отзывчивый интерфейс и надежную синхронизацию данных. 

Данный проект демонстрирует навыки проектирования клиент-серверной архитектуры, работы с асинхронными потоками данных и организации P2P-соединений.

## 🚀 Основные возможности

* **Обмен сообщениями в реальном времени:** Мгновенная доставка и обновление статуса текстовых сообщений благодаря реактивным подпискам (WebSockets/SSE).
* **Аудио и видеозвонки:** Полноценная интеграция протокола WebRTC для организации качественной медиа-связи напрямую между устройствами (Peer-to-Peer).
* **Кроссплатформенность:** Единая кодовая база на Flutter, поддерживающая плавную работу на Android, iOS и Web.
* **Легковесный и быстрый бэкенд:** Управление базой данных, пользователями, авторизацией и сессиями реализовано на базе PocketBase.
* **Современный UI/UX:** Чистый, адаптивный интерфейс с интуитивной навигацией, оптимизированный под различные разрешения экранов.

## 🛠️ Технологический стек

* **Frontend:** [Flutter](https://flutter.dev/) / Dart (управление состоянием, кастомные UI-компоненты, асинхронное программирование).
* **Backend & DB:** [PocketBase](https://pocketbase.io/) (Go, SQLite) — встраиваемый бэкенд с поддержкой Realtime-подписок из коробки.
* **Протоколы связи:** WebRTC (организация потоковой передачи аудио и видео данных с минимальной задержкой).

## 📂 Архитектурные особенности проекта

Кодовая база спроектирована с упором на разделение ответственности (Separation of Concerns), что упрощает дальнейшее масштабирование и тестирование:
* **Слой отображения (UI):** Изолированные, переиспользуемые виджеты.
* **Слой логики:** Четкое разделение бизнес-логики и интерфейса, управление состояниями экранов.
* **Слой данных (Data & Services):** Абстракция над сетевыми запросами к PocketBase и конфигурацией WebRTC-серверов (Signaling, STUN/TURN).

## 🛠️ Инструкция по развертыванию и запуску

Для успешного запуска проекта локально вам понадобятся установленный **Flutter SDK** стабильной версии и запущенный экземпляр **PocketBase**.

### 1. Подготовка бэкенда (PocketBase)
1. Скачайте PocketBase с официального сайта [pocketbase.io](https://pocketbase.io/).
2. Запустите сервер в терминале:
   ```bash
   ./pocketbase serve

```

3. Перейдите в панель администрирования (`http://127.0.0.1:8090/_/`) и создайте необходимые коллекции для пользователей и сообщений.

### 2. Клонирование и настройка клиента

Выполните следующие команды в терминале:

```bash
# Клонирование репозитория
git clone [https://github.com/AlexMikhin951/new_messenge.git](https://github.com/AlexMikhin951/new_messenge.git)

# Переход в директорию проекта
cd new_messenge

# Загрузка всех необходимых зависимостей и пакетов
flutter pub get

```

### 3. Конфигурация окружения

Откройте файл конфигурации проекта (например, `lib/constants.dart` или используемый `.env` файл) и укажите URL-адрес вашего запущенного сервера PocketBase:

```dart
const String baseUrl = '[http://127.0.0.1:8090](http://127.0.0.1:8090)'; // Локальный адрес сервера

```

### 4. Команды для запуска и сборки

**Запуск в режиме отладки (Development):**

```bash
flutter run

```

**Сборка релизной версии под Android (APK):**

```bash
flutter build apk --release

```

**Сборка для Web-платформы:**

```bash
flutter build web
